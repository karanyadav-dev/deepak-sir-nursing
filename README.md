# Deepak Sir — Nursing Exam Preparation Platform

Complete nursing competitive exam preparation platform with AI Assistant for NORCET, AIIMS Nursing, and other nursing exams.

## ✨ Features

- 📱 Android Mobile App (Python Kivy)
- 🖥️ Web Admin Panel (Next.js)
- 🔧 REST API Backend (Spring Boot)
- 🤖 AI Medical & Nursing Assistant
- 📝 MCQ Practice Engine
- 📋 Mock Test System
- 📚 Course Management
- 📊 Performance Analytics
- 🏆 Leaderboard & Gamification
- 📴 Offline Support
